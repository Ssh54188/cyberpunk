# 赛博朋克风格个人博客网站设计文档

## 1. 概述

### 1.1 项目背景
本项目旨在创建一个具有赛博朋克风格的个人博客网站，融合未来科技感与霓虹元素，为用户提供独特的视觉体验。网站将包含主页、登录注册页面以及管理员后台三个核心部分。

### 1.2 设计目标
- 营造强烈的赛博朋克氛围，通过霓虹色调、故障艺术效果和动态背景
- 提供直观易用的用户界面，确保功能性和美观性并重
- 实现响应式设计，适配不同设备屏幕尺寸
- 创建一致的视觉语言和交互体验

## 2. 视觉设计规范

### 2.1 色彩方案
| 颜色类型 | 色值 | 用途 |
|---------|------|------|
| 主背景色 | #0a0a1a | 页面背景 |
| 霓虹蓝色 | #00f0ff | 链接、按钮、高亮元素 |
| 霓虹紫色 | #bd00ff | 次要交互元素 |
| 霓虹粉色 | #ff00c8 | 强调元素 |
| 文字主色 | #e0e0e0 | 主要文字内容 |
| 文字次色 | #a0a0a0 | 次要文字内容 |

### 2.2 字体规范
- 主要字体：VT323 或类似等宽像素字体
- 备用字体：Courier New, monospace
- 标题大小：2.5rem - 3rem
- 正文大小：1.2rem
- 小字大小：0.9rem

### 2.3 视觉效果
- 故障艺术（Glitch）效果应用于标题
- 霓虹发光效果应用于按钮和交互元素
- 动态背景动画增强科技感
- 高对比度文字确保可读性

## 3. 网站架构设计

### 3.1 页面结构
1. 首页（个人博客主页）
2. 登录/注册页面
3. 管理员后台页面

### 3.2 导航结构
```
首页 (博客主页)
├── 学习日记
├── 创意脑洞
├── 学习进度
└── 留言区

登录/注册
├── 登录表单
└── 注册表单

管理员后台
├── 仪表盘
├── 用户管理
└── 留言管理
```

## 4. 首页设计

### 4.1 布局结构
```
+-----------------------------------------------------+
| 顶部区域：故障效果标题 + 横排导航栏                  |
+-----------+-----------------------------------------+
| 左侧      | 右侧主内容区                             |
| 侧边栏    | +---------------------------------------+ |
|           | | 学习日记模块                          | |
|           | +---------------------------------------+ |
|           | +---------------------------------------+ |
|           | | 创意脑洞模块                          | |
|           | +---------------------------------------+ |
|           | +---------------------------------------+ |
|           | | 学习进度模块                          | |
|           | +---------------------------------------+ |
|           | +---------------------------------------+ |
|           | | 留言区模块                            | |
|           | +---------------------------------------+ |
+-----------+-----------------------------------------+
| 底部区域：版权信息 + 赛博朋克语录                    |
+-----------------------------------------------------+
```

### 4.2 组件设计

#### 4.2.1 顶部区域
- 博客标题：应用故障艺术效果的霓虹文字
- 副标题：简洁的描述性文字
- 导航栏：居中横排，包含首页、学习日记、创意脑洞、学习进度、留言等导航项

#### 4.2.2 左侧侧边栏
- 个人头像：圆形带发光边框
- 个人名称：霓虹发光效果
- 身份描述：简短的个人介绍
- 登录/用户菜单：可展开的下拉菜单
- 学习数据统计：
  * 学习天数
  * 完成项目数
  * 掌握语言数
- 社交图标链接：GitHub、Twitter等社交平台链接

#### 4.2.3 右侧主内容区

##### 学习日记模块
- 日期显示：霓虹色时间戳
- 标签系统：不同颜色标识不同技术领域
- 内容展示：支持代码块的富文本内容
- 交互元素：点赞、分享按钮

##### 创意脑洞模块
- 卡片式布局：每个想法以独立卡片展示
- 视觉元素：图标、简短描述
- 交互效果：悬停时的霓虹发光效果

##### 学习进度模块
- 步骤展示：垂直排列的学习阶段
- 进度条：霓虹色动态进度指示器
- 状态标识：已完成/进行中/未开始

##### 留言区模块
- 评论列表：用户头像、昵称、时间、内容
- 输入框：多行文本输入区域
- 提交按钮：霓虹发光效果

#### 4.2.4 底部区域
- 版权信息：网站版权声明
- 赛博朋克语录：随机显示的未来主义名言

## 5. 登录/注册页面设计

### 5.1 页面布局
```
+-----------------------------------------------------+
| 左上角    | 顶部区域         | 右上角               |
| 返回主页  |                  |                      |
+-----------------------------------------------------+
|                                                     |
|                    主容器区域                        |
|                                                     |
|         +-------------------------------+            |
|         | 登录/注册切换标签              |            |
|         +-------------------------------+            |
|         |                               |            |
|         |      表单内容区域              |            |
|         |                               |            |
|         +-------------------------------+            |
|                                                     |
+-----------------------------------------------------+
| 右下角：管理员登录入口                               |
+-----------------------------------------------------+
```

### 5.2 表单设计

#### 登录表单
- 用户名输入框：带用户图标前缀
- 密码输入框：带锁图标前缀
- "记住我" 复选框
- "忘记密码" 链接
- 登录按钮：霓虹发光效果
- 切换到注册的链接

#### 注册表单
- 用户名输入框
- 邮箱输入框
- 密码输入框
- 确认密码输入框
- 同意服务条款复选框
- 注册按钮：霓虹发光效果
- 切换到登录的链接

### 5.3 交互反馈

#### 登录失败弹窗
- 居中显示在屏幕中央
- 50%透明度黑色遮罩层
- 2秒后自动关闭
- 0.3秒淡入淡出过渡动画
- 文字大小不小于14px

#### 登录成功弹窗
- 居中显示在屏幕中央
- 透明背景遮罩层
- 2秒后自动跳转至主页
- 平滑自然的过渡动画

## 7. 响应式设计

### 7.1 断点设置
- 手机端：≤ 768px
- 平板端：769px - 1024px
- 桌面端：≥ 1025px

### 7.2 布局调整
- 手机端：垂直堆叠布局，导航栏折叠为汉堡菜单
